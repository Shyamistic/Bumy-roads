## Stack and command notes observed in the target project

### Current structure and capabilities

- Root frontend: React 19, Vite 7, JavaScript/JSX, Sass, ESLint. The current root `src/App.jsx` imports React Three Fiber, Drei, Three.js, GSAP, PostHog, Sanity data, the original audio context, device profiling, and texture preloading.
- Nested `portfolio-itom/` is a separate Sanity Studio with its own `package.json`, `package-lock.json`, and `UNLICENSED` package metadata. It is not part of the Signal Run build and must not be altered or deployed.
- The root Vite configuration currently injects a Sanity SEO plugin and `/start` middleware. `public/start/` and `scripts/test-start.mjs` are isolated legacy content, not a Signal Run dependency.
- There is no `tsconfig.json`, no package `test` script, and no `typecheck` script. This redesign remains JavaScript-only and does not add a test framework.
- The new app will rely on broadly available semantic HTML, CSS media queries, ordinary anchors, native `<audio>`, and optional browser media events. It deliberately has no WebGL/Canvas, animation frame loop, analytics, device probing, microphone request, `SpeechRecognition`, or `getUserMedia` use.
