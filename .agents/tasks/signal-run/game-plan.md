# Implementation Plan

## Scope and decisions

- Replace the active WebGL corridor rather than adapting it. The current entry point mounts React Three Fiber, preloads protected upstream textures, initializes audio, queries Sanity, and starts PostHog; a semantic DOM trail is the only way to meet the low-GPU, non-3D, no-autoplay brief without carrying those behaviors forward.
- Keep the downloaded upstream archive intact but exclude its `public/` assets from the new build with Vite's dedicated `public-signal/` directory. The upstream README says its personal assets and copy cannot be reused, while `LICENSE` requires preserving the MIT notice; this approach preserves both facts without shipping protected assets.
- Use native hash links and ordinary document scrolling as the primary route. React only renders the content and enables intentional audio controls, so touch scrolling, clicks, and keyboard activation work without a canvas, game loop, microphone, analytics, or device profiling.
- Treat the provided resumes as user-authorized claim sources and render each statement with an explicit status (`Verified public source`, `Resume-backed / public-safe summary`, or `Proposed, not run`). Do not turn a source link, a proposed experiment, an empty media slot, or a project marketing claim into evidence it does not contain.
- Do not implement browser speech navigation. It is optional, would introduce microphone-consent and browser-support complexity, and offers less value than a strong click, scroll, and keyboard route for this portfolio.

### Validation baseline recorded during planning

- `npm ci` completed on Node `v24.16.0` / npm `11.13.0`, with existing dependency peer warnings and 62 audit findings in the old 3D dependency tree.
- `npm run build` currently **passes** in about 24 seconds, but builds the original ITom WebGL/CMS experience and reports a 1.5 MB minified entry chunk. It is not evidence that the requested portfolio already works.
- `npm run lint` currently **fails** with 240 errors and 32 warnings across starter/legacy files, including `public/start`, scripts, and 3D code. The replacement deliberately narrows the lint target to the newly active source tree instead of hiding problems in code that will not ship.
- `node --test scripts/test-start.mjs` currently **fails 7 of 8** tests because the retired standalone `/start` HTML and script disagree. It is unrelated to the requested portfolio and will not be expanded into a new test suite.
- No root test script, TypeScript config, or type-check command exists. The only relevant automated release commands after implementation are `npm run lint` and `npm run build`, followed by the documented manual browser checks.
