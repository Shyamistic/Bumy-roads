# The Signal Run

The Signal Run is Shyam Sharma’s five-stop, evidence-led portfolio trail. It presents public-safe project evidence, documented decisions and mistakes, and a proposed growth test. It is a normal React and HTML route, not a WebGL experience.

## Source-status rules

- **Nexus Prime** uses a verified public source and the provided résumé. Its figures are diagnostic-evaluation figures, not production incident outcomes.
- **A.S.T.R.A.** and **Vayu** are linked to verified public repositories. A.S.T.R.A. remains defensive, authorized, sandbox-only work. Vayu’s stale but plausible output is a documented validation failure.
- **VRI + Wordwatch** are résumé-backed, public-safe summaries. They deliberately omit confidential artefacts, client details, and internal material.
- **One Breath, One Message** and the $3,000 field kit are proposals. They have no participant research, analytics, conversion results, or campaign outcomes to claim.

## Asset and browser boundaries

This build uses original CSS and inline SVG composition. It does not reuse Tomasz Szmajda / ITom personal images, textures, 3D assets, sounds, or copy. It uses no canvas or WebGL, analytics, autoplay, microphone access, speech recognition, or generated voice. Voice Notes only load an audio URL after Shyam has supplied an authentic recording and marked its manifest item `cleared`.

## Local commands

From the repository root:

```bash
npm ci
npm run lint
npm run build
npm run dev
npm run preview
```

Use the development server to inspect interactions. Use the preview server to inspect the production build. Check desktop and 375 px mobile layouts, native hash navigation, keyboard controls, reduced motion, high contrast or forced colors, and the no-JavaScript summary.
